Interactive version of the Blip Optimized location step on mobile. The map only appears for Drop a pin. Each area starts at a suggested radius, and the radius changes only inside Edit.

Things to try

  1. Search "Oak" or "San", tap + on a few places, then Add.
  2. Try "Oakhurst" or "San Ardo": places without signs say Not available and can't be added.
  3. Tap Drop a pin: the map opens at the last area or current location. With location off and no areas, it opens on the whole US; search to jump in.
  4. In Add areas, type a place and use "Drop a pin near…" when the listed place isn't quite right.
  5. In Edit, tap Change: "Drop a pin near" the current area nudges it; picking a result swaps it.
  6. Set Location access to Not allowed, then tap Current location or Drop a pin.
  7. Tap Edit on an area, open the radius, and pick a bigger one. The row then reads "Edited".
  8. Remove an area from Edit, then Undo.

Decisions shown

  • Search first; the map is only for placing one pin at a time.
  • Drop a pin on the start screen goes straight to the map. Search screens also offer "Drop a pin near…", which opens it close up.
  • Zoomed out past state level (radius tops out at 50 mi), tapping the map drops the pin there and zooms in, as in the current product. Up close, the map moves under a fixed pin.
  • Suggested radius per area, picked so every listed area has signs.
  • Radius changes only inside Edit, so larger radii aren't picked by accident.
  • "Up to N signs": ads rotate across these signs; budget sets how often each plays.
  • No error colors. Places without signs read "Not available".
