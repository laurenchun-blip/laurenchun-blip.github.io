Decisions so far

  • Mockups aren’t saved. They’ll attach to the campaign, so My Library has no Mockups tab.
  • Empty library uses the centered null state (option 6).
  • The maker banner moves to the dashboard, using option 5.
  • Upload in the banner is for new users only. Existing users already know how to upload, so their banner sells Generate alone.
  • Creative details open in a side panel, not a separate page.
  • Campaign details open in a peek drawer. The footer has Edit and Share, and there’s no separate full details page. Pause and Start live in the ⋮ menu and on the cards. On phones, Details collapses so the drawer fits on one screen.

Using the prototypes

  • The bar at the bottom of each prototype jumps between screens. Scenario sets what the account already has. Step picks a screen.
  • The left rail moves between prototypes, the way it moves between pages in the product.
  • All prototypes in that bar comes back here.
