Matches the Figma Style=Neutral components. Step cards are white with the page's 1px grey border; finished steps get a faint blue tint; the next step has a 2px blue border, a Next pill and a full-width button; illustrations sit in 32px icon tiles. While Getting started shows, the performance empty state has no Create campaign link; header Create is the only filled button.
Draft: the first-campaign step completes only when any campaign is submitted for review. While a draft exists the card reads "Finish your first campaign" and "Finish campaign" reopens the most recently edited draft in the builder where it was left. With several drafts the card names that draft and the count; all drafts stay in Campaigns.
Payment issue: one generic state for any card problem (declined, expired, and so on), so the widget never has to know the reason. The payment card owns it: "Action needed" pill, "Update payment method", "There was an issue with the card on file." and an "Update payment" button that opens Update payment on the Billing page. It drops out of the done count; the goal card only reflects the effect ("On hold", no second button). Card details never show on the widget.
Campaigns strip: right-now counts above the chart (they ignore the chart's date filter). Running and In review are the requested scope; "Needs attention" (toggle in the bar) is optional and counts only campaigns that should be running but can't (rejected creative, payment issue), never ended or archived ones, capped at "9+". Each count opens the Campaigns list at that section. "View all campaigns" hides only when no campaign or draft exists. "Widget done" shows an established account after Getting started has gone.
Open questions: count the goal in "of 4"? Dismiss before done, and once live? Does the widget hide the payment issue once an account-level payment banner exists? "Needs changes" stays generic on the widget: "See details" opens the campaign details drawer, which owns the reason and the fix, so any rejection reason works. Use Approve in the bar to continue.
